ytmeta
YouTube Metadata Viewer

Video metadata from the terminal or your browser. Statistics, codecs, chapters, subtitles, tags, and more.

View on GitHub Get Started

Features

The terminal and web versions cover the same ground, with some differences in detail and layout.

📊

Statistics

Views, likes, and comments, abbreviated to K/M. Estimated watch hours too — in the Technical Details panel in the terminal, in Statistics on the web.

⚙️

Technical Details

Resolution, FPS, codecs, bitrate, and file size for the selected format.

📝

Subtitles & Captions

Manual subtitles listed by language with their formats in the terminal, and the first 10 auto-caption languages before the rest are collapsed. The web UI lists languages only, with auto-captions as a count.

🎬

Chapters

Video chapters with timestamps and durations.

🏷️

Tags

All video tags — colored pills on the web, colored #tag text in the terminal.

🌐

Web UI

Dark-themed browser interface with metadata panels, thumbnail banner, and formats table.

CLI Options

Filter and control the output with these flags.

FlagDescription
-j, --jsonOutput raw metadata as JSON
--stats-onlyShow only views, likes, comments
--tags-onlyShow only tags
--chapters-onlyShow only chapter information
--no-subtitlesHide subtitles/captions panel
--no-formatsHide the available formats table
--no-descriptionHide the description panel

Get Started

Clone the repo, then run. Not published to PyPI.

CLI

pip install -e .
ytmeta <youtube-url>

Web UI

pip install -e .
python web/server.py

You can also run without installing, given yt-dlp, rich, and flask on the path: python3 -m ytmeta.cli <youtube-url>.
