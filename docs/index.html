ytmeta
YouTube Metadata Viewer

Video metadata from the terminal or your browser. Statistics, codecs, chapters, subtitles, tags, and more.

View on GitHub Get Started

Features

The terminal and web versions show the same metadata, just formatted differently.

📊

Statistics

Views, likes, comments, and estimated watch hours, formatted with K/M abbreviations.

⚙️

Technical Details

Resolution, FPS, codecs, bitrate, and file size for the selected format.

📝

Subtitles & Captions

Manual subtitles and auto-generated captions listed by language with available formats.

🎬

Chapters

Video chapters with timestamps and durations.

🏷️

Tags

All video tags displayed as colored pills.

🌐

Web UI

Dark-themed browser interface with metadata panels, thumbnail banner, and formats table.

CLI Options

Filter and control the output with these flags.

FlagDescription
-j, --jsonOutput raw metadata as JSON
--stats-onlyShow only views, likes, comments
--tags-onlyShow only tags
--chapters-onlyShow only chapter information
--no-subtitlesHide subtitles/captions panel
--no-formatsHide the available formats table
--no-descriptionHide the description panel

Get Started

Install and run in two commands.

CLI

pip install -e .
ytmeta <youtube-url>

Web UI

pip install -e .
python web/server.py
